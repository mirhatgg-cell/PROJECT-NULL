# PROJECT: NULL — V7, визуальная детализация

Готовый файл: [PROJECT_NULL_INTERIORS_V7_DETAIL.rbxlx](artifacts/PROJECT_NULL_INTERIORS_V7_DETAIL.rbxlx).

Первый проход охватывает камеру погружения E-03, операторскую E-04 и медицинскую E-06. За основу взят загруженный V6; исходный файл сохранён без изменений в `source/`. Текстовый документ использован как описание художественного направления проекта.

## Что добавлено

| Помещение | Новое оформление |
| --- | --- |
| E-03 — погружение | Рама с опорами и креплениями, сенсорная подвеска над креслом, боковые датчики, разъёмы и закреплённые кабели, корпус подключения, маркировка платформы и макет аварийного поста. |
| E-04 — операторская | Обозначения трёх рабочих постов, карточки процедур, переговорные устройства с микрофонами и кабелями, настенные акустические панели, доска протокола, подвесы потолочных направляющих и плинтус. |
| E-06 — медицинская | Умывальник с открытой чашей, смеситель, слив и настенные подключения, дозатор и бумажные полотенца, закрытая урна, тележка с колёсами, полками и закрытыми контейнерами. |

Новые модели используют встроенные материалы Roblox, отдельные корпуса, опоры и таблички; загрузка сторонних ассетов не требуется. Всё новое оборудование в этой версии — статическое визуальное оформление. Для него не добавлены игровые действия, медицинские процедуры, звук или анимации. Макет аварийной кнопки явно подписан в самой модели.

## Открыть и осмотреть

1. В Roblox Studio открыть `artifacts/PROJECT_NULL_INTERIORS_V7_DETAIL.rbxlx` через **File → Open from File**.
2. В Explorer перейти к `Workspace → PROJECT_NULL_ARCH_P01 → Equipment → Visual_Detail_V7`.
3. Выделить `E03_Immersion_Detail`, `E04_Operator_Detail` или `E06_Medical_Detail` и нажать **F**, чтобы навести камеру.
4. Осмотреть модели с уровня персонажа, при включённом освещении и с разных сторон. Превью рядом с файлом показывает геометрию в разрезе; это не снимок из Studio.
5. В режиме **Play** проверить существующие двери, экраны и органы управления, включая питание и регулировку кроватей. Сравнить освещение и частоту кадров с V6 на целевых устройствах.

## Если скачивание файла недоступно

Открыть свой исходный V6 в Roblox Studio, остановить Play и включить **View → Command Bar**. Скопировать весь текст `artifacts/INSTALL_V7_COMMAND_BAR.luau`, вставить в Command Bar и выполнить. Установщик автономен: `JSONDecode` разбирает встроенные данные, сетевых запросов нет. Он создаёт те же 345 объектов (292 детали) в группе `Visual_Detail_V7`, сохраняя исходные объекты V6. При наличии этой группы повторная установка останавливается. После установки сохранить место через **File → Save to File**.

Новая группа собирается отдельно и добавляется после успешного создания с записью Undo. Установщик проверен в Lua VM с имитацией Roblox API: перенос всех свойств, повторный запуск, режим Play, отказ записи Undo и откат после ошибки. Эта проверка не заменяет запуск в Roblox Studio.

## Проверки

В текущей среде выполнены разбор XML, проверка ссылок и матриц поворота, границ новых моделей и указанных дверных проёмов. Проверены неизменность всех свойств и иерархии исходных объектов, трёх серверных скриптов и 195 ClickDetector. Все новые детали закреплены; у них выключены `CanCollide`, `CanTouch` и `CanQuery`, чтобы оформление не участвовало в проверке кликов исходных скриптов.

Числа и контрольные суммы записаны в [VALIDATION_V7.json](artifacts/VALIDATION_V7.json). Проверки в Roblox Studio в этой среде не выполнялись; внешний вид, поведение в Play и производительность требуют проверки в движке.

## Повторить сборку

Из корня репозитория, с Python 3.12:

```sh
python3 tools/build_v7.py
python3 tools/validate_v7.py
python3 tools/export_studio_installer.py
```

Сборка и проверка используют стандартную библиотеку Python. Повторная сборка из неизменённого V6 даёт идентичный файл V7. Для отдельного превью:

```sh
python3 tools/render_v7.py
```

Для рендера используются NumPy и Matplotlib; проверенные версии указаны в `tools/requirements-preview.txt`. Живые процессы и Roblox Studio для создания XML не требуются.

Отдельная проверка установщика: `python3 tools/test_studio_installer.py` с установленным `lupa==2.6`. Она выполняет код в тестовой имитации редактора.

## Изменение и откат

Геометрия описана в `tools/v7_immersion.py`, `tools/v7_control.py` и `tools/v7_medical.py`. Сборщик добавляет одну группу `Visual_Detail_V7` к исходному V6, не редактируя старые объекты. Для удаления всего нового оформления достаточно удалить эту группу в Studio. Исходный V6 также доступен в `source/PROJECT_NULL_INTERIORS_V6.rbxlx`.
